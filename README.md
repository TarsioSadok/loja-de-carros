# 🚗 Loja de Carros

Projeto de uma página web de loja de carros, desenvolvido com HTML e CSS para praticar a construção e a estilização de interfaces.

## 📌 Sobre o projeto

Este projeto simula a página de uma loja de carros e foi criado como exercício de front-end, com foco em estrutura semântica em HTML e layout em CSS.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- Git e GitHub

## ▶️ Como executar

1. Clone o repositório:

   ```bash
   git clone https://github.com/TarsioSadok/loja-de-carros.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd loja-de-carros
   ```

3. Abra o arquivo `index.html` no seu navegador.

## 📚 Aprendizados

- Estruturação de páginas com HTML
- Estilização e organização de layout com CSS
- Versionamento de código com Git e GitHub
